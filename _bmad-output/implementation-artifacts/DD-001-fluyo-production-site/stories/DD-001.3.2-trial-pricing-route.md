# DD-001.3.2: Trial And Pricing Route

**Epic:** 3 - Teachers & Proof and Trial & Pricing implementation  
**Status:** Ready  
**Size:** Large  
**Depends On:** `DD-001.1.2`, `DD-001.1.3`, `DD-001.2.2`  
**Route:** `/pricing`  
**Source:** DD-001 scope; final UX layout source; page layout schema Trial & Pricing block; TS-001 HP-001 through HP-003, ER-001, ER-002, EC-002, EC-003  

## Goal

Build the Trial & Pricing page that clarifies the paid first step, lesson formats, included value, practical FAQ, and Telegram booking with path and format context.

## Required Sections

1. Global Header from the default layout.
2. Trial First Step.
3. Individual Format.
4. Pair Format.
5. Mini-Group Format.
6. What Is Included.
7. Practical FAQ.
8. Final Booking CTA.
9. Footer / Contact Strip from the default layout.

## Objects And Components

| Object | Type | Behavior | States |
| --- | --- | --- | --- |
| Trial first step | Pricing hero | Shows paid trial price/duration and included value when approved. | generic, exam, kids, adult, hidden/blocked |
| Format block | Pricing block | Shows individual, pair, and mini-group format fit and terms. | approved, hidden, review |
| Included item | Info item | Shows teacher matching, live lesson, materials, feedback/progress. | approved, hidden |
| FAQ row | Accordion | Answers practical payment, schedule, online format, language, rescheduling questions. | collapsed, expanded, hidden |
| Final booking CTA | CTA section | Opens Telegram with path/format/source route/locale context or generic fallback. | path-aware, format-aware, generic |

## Implementation Notes

- Use `app/pages/pricing.vue`.
- Known query contexts: `/pricing?path=exam`, `/pricing?path=kids`, `/pricing?path=adult`.
- Unknown query context falls back to generic pricing content without a visible error.
- Pricing content is launch-sensitive; public rendering must obey the production-content validation.
- FAQ answers about payment, scheduling, rescheduling, online format, and trial terms must be approved or hidden.
- Emit `pricing_view`, `telegram_click`, and `telegram_context` through the tracking adapter.

## Acceptance Criteria

### Agent-Verifiable

- [ ] `/pricing` loads directly.
- [ ] `/pricing?path=exam`, `/pricing?path=kids`, and `/pricing?path=adult` adapt heading/helper or CTA state to known context.
- [ ] `/pricing?path=unknown` falls back to generic pricing content without broken state.
- [ ] Trial First Step, three format blocks, included items, FAQ, final CTA, and footer render in approved order.
- [ ] Telegram CTA opens through shared helper with available path/format context.
- [ ] Missing path or format context uses a generic paid-trial fallback.
- [ ] Rapid CTA clicks do not create invalid URLs or malformed tracking payloads.
- [ ] `pricing_view`, `telegram_click`, and `telegram_context` emit with available context.
- [ ] production/outside public scope price, trial, or policy FAQ records do not render as approved public truth in production build.
- [ ] `npm run build` passes.

### User-Evaluable

- [ ] The paid trial and format options are understandable before Telegram.
- [ ] Context-aware pricing feels helpful without hiding generic booking.
- [ ] FAQ answers feel practical and trustworthy, not speculative.
