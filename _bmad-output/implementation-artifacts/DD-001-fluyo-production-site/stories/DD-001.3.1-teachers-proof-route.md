# DD-001.3.1: Teachers And Proof Route

**Epic:** 3 - Teachers & Proof and Trial & Pricing implementation  
**Status:** Ready  
**Size:** Large  
**Depends On:** `DD-001.1.3`, `DD-001.2.2`  
**Route:** `/teachers`  
**Source:** DD-001 scope; final UX layout source; page layout schema Teachers & Proof block; TS-001 HP-002, ER-004, EC-005, AX-005  

## Goal

Build the Teachers & Proof page so trust-sensitive visitors can inspect teacher, credential, lesson, and outcome evidence before booking or comparing full pricing.

## Required Sections

1. Global Header from the default layout.
2. Trust Header.
3. Teacher Cards.
4. Credentials Proof.
5. Lesson Proof.
6. Results And Testimonials.
7. Trust CTA Strip.
8. Footer / Contact Strip from the default layout.

## Objects And Components

| Object | Type | Behavior | States |
| --- | --- | --- | --- |
| Trust header | Section header | Frames page as proof/checking page. | localized uk/en |
| Teacher card | Content card | Shows approved teacher profile, audience fit, portrait, credentials. | approved, hidden, review |
| Credential proof item | Proof item | Shows approved certificate/training/method evidence with alt text. | approved, hidden, review |
| Lesson proof review | Proof/media item | Shows approved or illustrative lesson material with privacy-safe metadata. | approved, hidden, review |
| Testimonial/result item | Proof item | Shows concise approved outcomes or testimonials. | approved, hidden |
| Trust CTA strip | CTA section | Routes to `/pricing`, `/programs`, or Telegram with available context. | generic, path-aware |

## Implementation Notes

- Use `app/pages/teachers.vue`.
- Teacher/proof/testimonial rendering must consume content-readiness helpers from `DD-001.1.3`.
- If real teacher profiles are outside public scope, hide individual teacher cards or render neutral process copy only if approved.
- Do not imply measured outcomes, guaranteed improvement, or verified results without approved proof.
- Meaningful media requires accurate alt text; decorative media should be hidden from assistive tech.
- Emit `teacher_proof_view` when proof surfaces are observed or activated.
- Do not duplicate Home path chooser or full pricing table here.
