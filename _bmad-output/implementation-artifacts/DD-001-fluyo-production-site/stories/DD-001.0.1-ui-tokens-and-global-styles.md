# DD-001.0.1: UI Tokens And Global Styles

**Epic:** 0 - Extract in-code UI foundation  
**Status:** review  
**Size:** Medium  
**Depends On:** None  
**Source:** DD-001 implementation workstream `epic-0-ui-foundation`; architecture AD-7  

## Goal

Create the minimal Tailwind/SCSS in-code visual foundation for the four-page production site before any route-specific build-out.

## Build Scope

- Add `app/assets/css/tailwind.css` as the Tailwind import and project `@theme` token source.
- Add `app/assets/scss/main.scss` for authored global base styles.
- Wire both style files through `nuxt.config.ts`.
- Wire Tailwind through the official `@tailwindcss/vite` plugin and enable SCSS through Sass.
- Keep `app/app.vue` starter replacement for `DD-001.0.2`; this story only establishes global styling inputs.

## Token Requirements

- Tailwind `@theme` color tokens for page, surface, inverse surface, text, muted text, hairline border, burgundy accent, subdued accent, focus, and danger/warning content states.
- Tailwind `@theme` typography tokens for body, small, eyebrow, section heading, display heading, line-height, and font weight.
- Tailwind `@theme` spacing tokens for page gutters, section rhythm, component gaps, card padding, and compact controls.
- Tailwind `@theme` border/radius tokens for hairline borders and square geometry. Default radius should preserve the no-rounded-card direction.
- Tailwind-backed z-index tokens for header, mobile menu, overlays, and focus treatments.
- Tailwind-backed motion tokens for short, restrained transitions and reduced-motion handling.

## Implementation Notes

- Use Tailwind theme variables as the token source of truth.
- Keep raw brand color values inside `app/assets/css/tailwind.css`; components should consume Tailwind utilities backed by project tokens.
- Use SCSS for authored global base styles, not as a parallel token source.
- Do not introduce a standalone design-system package.
- Preserve the approved visual direction: editorial spacing, square geometry, hairline borders, black/ivory/deep burgundy emphasis, no decorative shadows.
- Do not use viewport-width font sizing or negative letter spacing.
- Add base focus styles that remain visible on light and dark sections.

## Acceptance Criteria

- [x] `tailwindcss`, `@tailwindcss/vite`, and `sass` are installed as dev dependencies.
- [x] `app/assets/css/tailwind.css` exists, imports Tailwind, and defines color, typography, spacing, border/radius, z-index, and motion tokens in `@theme static`.
- [x] `app/assets/scss/main.scss` exists and consumes Tailwind theme variables for global body, links, focus, images, and reduced-motion behavior.
- [x] `nuxt.config.ts` includes the Tailwind CSS and SCSS files and registers the Tailwind Vite plugin.
- [x] Legacy `app/assets/css/tokens.css` and `app/assets/css/main.css` are absent.

- [x] No global style uses negative `letter-spacing`.
- [x] Decorative `box-shadow` is absent from global tokens and base styles.
- [x] `npm run test:ui-foundation` passes.
- [x] `npm run build` passes.

### User-Evaluable

- [x] Foundation feels premium, restrained, and school-appropriate rather than decorative or generic.
- [x] Global focus treatment is visible without feeling visually noisy.
