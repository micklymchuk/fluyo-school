# DD-001.0.1: UI Tokens And Global Styles

**Epic:** 0 - Extract in-code UI foundation  
**Status:** Ready  
**Size:** Medium  
**Depends On:** None  
**Source:** DD-001 implementation workstream `epic-0-ui-foundation`; architecture AD-7  

## Goal

Create the minimal in-code visual foundation for the four-page production site before any route-specific build-out.

## Build Scope

- Add `app/assets/css/tokens.css`.
- Add `app/assets/css/main.css`.
- Wire both CSS files through `nuxt.config.ts`.
- Keep `app/app.vue` starter replacement for `DD-001.0.2`; this story only establishes global styling inputs.

## Token Requirements

- Color tokens for page, surface, inverse surface, text, muted text, hairline border, burgundy accent, subdued accent, focus, and danger/warning content states.
- Typography tokens for body, small, eyebrow, section heading, display heading, line-height, and font weight.
- Spacing tokens for page gutters, section rhythm, component gaps, card padding, and compact controls.
- Border tokens for hairline borders and square geometry. Default radius should preserve the no-rounded-card direction.
- Z-index tokens for header, mobile menu, overlays, and focus treatments.
- Motion tokens for short, restrained transitions and reduced-motion handling.

## Implementation Notes

- Use CSS custom properties as the source of truth.
- Keep raw brand color values inside `tokens.css`; components should consume variables.
- Do not introduce a CSS framework or standalone design-system package.
- Preserve the approved visual direction: editorial spacing, square geometry, hairline borders, black/ivory/deep burgundy emphasis, no decorative shadows.
- Do not use viewport-width font sizing or negative letter spacing.
- Add base focus styles that remain visible on light and dark sections.

## Acceptance Criteria

### Agent-Verifiable

- [ ] `app/assets/css/tokens.css` exists and defines color, typography, spacing, border, z-index, and motion custom properties.
- [ ] `app/assets/css/main.css` exists and consumes token variables for global body, links, focus, images, and reduced-motion behavior.
- [ ] `nuxt.config.ts` includes the global CSS files.
- [ ] No global text style uses `vw` units for font size.
- [ ] No global style uses negative `letter-spacing`.
- [ ] Decorative `box-shadow` is absent from global tokens and base styles.
- [ ] `npm run build` passes.

### User-Evaluable

- [ ] Foundation feels premium, restrained, and school-appropriate rather than decorative or generic.
- [ ] Global focus treatment is visible without feeling visually noisy.

## Verification

- Run `npm run build`.
- Scan the new CSS for `font-size: *vw`, negative `letter-spacing`, and decorative `box-shadow`.
- In a browser after later route stories, verify focus outlines are visible in header, CTA, cards, and FAQ controls.

## Out Of Scope

- Content records.
- Header/footer layout.
- Public copy.
