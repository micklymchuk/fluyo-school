# DD-001.2.2: Learning Paths Route

**Epic:** 2 - Home and Learning Paths implementation  
**Status:** Ready  
**Size:** Large  
**Depends On:** `DD-001.2.1`  
**Route:** `/programs`  
**Source:** DD-001 scope; final UX layout source; page layout schema Learning Paths block; TS-001 HP-001 through HP-003 and EC-001  

## Goal

Build the Learning Paths page that gathers Exam Preparation, Kids & Parents, and Adults Speaking into one comparison route with path-aware CTAs.

## Required Sections

1. Global Header from the default layout.
2. Learning Paths Header.
3. Exam Preparation.
4. Kids & Parents.
5. Adults Speaking.
6. Path Price Hints.
7. Learning Paths CTA Strip.
8. Footer / Contact Strip from the default layout.

## Objects And Components

| Object | Type | Behavior | States |
| --- | --- | --- | --- |
| Learning Paths header | Section header | Orients visitors to compare path fit. | localized uk/en |
| Exam section | Program panel | Shows exam fit, seriousness, structure, diagnostic-trial cue. | default, anchor target |
| Kids section | Program panel | Shows parent reassurance, child engagement, progress visibility cue. | default, anchor target |
| Adults section | Program panel | Shows adult recognition, real-life speaking situations, supportive method cue. | default, anchor target |
| Path price hint | Price hint | Shows concise path-specific price signal when gate allows. | approved, hidden, review |
| CTA strip | Section CTA | Routes to `/pricing?path=exam|kids|adult`, `/teachers`, or Telegram with context. | selected path, generic |

## Implementation Notes

- Use `app/pages/programs.vue`.
- Anchor ids must be stable: `exam-preparation`, `kids-parents`, `adults-speaking`.
- Direct deep links must land with readable header offset.
- Program sections should use shared section/card primitives from Epic 0.
- Do not create separate exam, kids, or adult routes.
- Do not include full pricing table, full teacher gallery, full testimonial wall, or long FAQ.
