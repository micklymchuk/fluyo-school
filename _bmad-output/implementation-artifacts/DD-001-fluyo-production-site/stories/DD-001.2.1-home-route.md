**Status:** Ready

## Goal

Build the Home page that introduces Fluyo, routes visitors into the right learning path, shows compact proof, and provides enough price clarity to continue.

## Required Sections

1. Global Header from the default layout.
2. Hero.
3. Path Cards: Exam, Kids & Parents, Adults Speaking.
4. Proof Snapshot: teacher-led proof, progress proof, trial step proof.
5. Trial & Prices Preview.
6. Footer / Contact Strip from the default layout.

## Objects And Components

| Object | Type | Behavior | States |
| --- | --- | --- | --- |
| Home hero | Section | Communicates Fluyo promise and primary next step. | localized uk/en |
| Exam path card | Path card | Routes to `/programs#exam-preparation`; emits `path_card_click`. | default, hover, focus |
| Kids path card | Path card | Routes to `/programs#kids-parents`; emits `path_card_click`. | default, hover, focus |
| Adults path card | Path card | Routes to `/programs#adults-speaking`; emits `path_card_click`. | default, hover, focus |
| Proof snapshot item | Proof item | Shows compact teacher/progress/trial cues without fake claims. | approved, hidden, preview |
| Trial price preview | Price preview | Shows compact paid-trial and format signal when content gate allows it; emits `price_preview_view`. | approved, hidden, preview |
| Telegram CTA | CTA | Opens Telegram through centralized helper with generic or selected context. | generic, path-aware |

## Implementation Notes

- Use `app/pages/index.vue`.
- Use section components under `app/components/sections/`.
- Home must not include full teacher gallery, long FAQ, detailed methodology, full testimonials, or full pricing table.
- Path cards should be accessible links, not click-only divs.
- A hint of the following section should remain visible below the first viewport where applicable.
- Preserve bilingual structure; long Ukrainian and English strings must wrap cleanly.
