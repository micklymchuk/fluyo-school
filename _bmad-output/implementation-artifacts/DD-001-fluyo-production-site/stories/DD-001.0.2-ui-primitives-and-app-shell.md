## Objects And Components

| Component | Type | Behavior | States |
| --- | --- | --- | --- |
| `UiButton` | UI primitive | Provides shared button/control styling, sizing, disabled, and loading behavior for native buttons and link-like controls. | default, compact, primary, secondary, ghost, disabled/loading |
| `UiButtonLink` | UI primitive | Renders internal links, external links, and button-like actions with consistent sizing. | default, hover, focus, active, disabled/loading if needed |
| `UiIconButton` | UI primitive | Renders accessible icon-only actions through `UiButtonLink`. | default, compact, primary, secondary, ghost, disabled/loading |
| `UiSection` | Section primitive | Provides section rhythm, max width, heading slot, content slot, and optional inverse theme. | default, compact, spacious, inverse |
| `UiCard` | UI primitive | Reusable bordered surface for path cards, proof items, pricing blocks, and teacher cards. | default, interactive, selected, hidden |
| `UiAccordion` | UI primitive | Accessible accordion behavior for FAQ rows. | collapsed, expanded, focus |
| `AppHeader` | Navigation | Displays logo, route links, language control slot, Instagram link, Telegram CTA. | desktop, mobile, active route |
| `MobileNav` | Navigation | Collapsed mobile route list with same order as desktop and distinct Telegram action. | closed, open, focus-trapped or focus-managed |
| `LanguageControl` | Navigation | Lets users switch Ukrainian and English via locale composable integration in later stories. | uk, en, focus |
| `FooterContactStrip` | Navigation | Repeats key routes and contact actions. | default |

## Implementation Notes

- UI primitives must not own route-specific public prose.
- Global custom Tailwind tokens remain the styling source of truth in `app/assets/css/tailwind.css`; component code should consume utilities backed by those tokens.
- UI primitives should use readable component-local classes in Vue templates, backed by Tailwind `@apply` styles in the same component `<style>` block.
- Use names such as `.section-header`, `.header-link`, or `.card-surface` for meaningful blocks so templates avoid long inline Tailwind utility strings.
- Component `@apply` rules must use token-backed Tailwind utilities such as project color, typography, spacing, radius, z-index, and motion utilities; do not hard-code raw brand values inside component CSS.
- Keep `app/assets/css/tailwind.css` focused on Tailwind import and global project `@theme` tokens, and keep `app/assets/scss/main.scss` for global/base styling.
- Props should accept labels, links, variant names, and contextual attributes.
- Mobile nav must close on route navigation and not leave duplicate active states.
- Header route order: Home, Learning Paths, Teachers & Proof, Trial & Pricing.
- Telegram remains a visually distinct primary action.
- Instagram appears in header, footer, and the opened mobile menu as an icon-only contact action.
