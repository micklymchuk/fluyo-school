## Overview

**Page Purpose:** Olena reads parent/student proof, resolves practical questions, then clicks Telegram ready to book.

**User Situation:** Olena has seen the kids path, teacher proof, and lesson experience. She is close to contacting Fluyo, but still needs final evidence, practical answers, and a clear low-friction booking step.

**Success Criteria:** Olena sees credible proof without exaggerated claims, answers her practical questions about trial, schedule, format, payment, and child fit, then opens Telegram with child-specific booking context.

**Entry Points:**
- Lesson Experience CTA
- Navigation menu
- Pricing section scroll continuation
- Direct anchor link to `#results-testimonials-faq`

**Exit Points:**
- Final Telegram booking click
- Instagram profile visit for additional social proof
- Continue browsing earlier sections if she needs teacher, pricing, or lesson details again

## Layout Structure

This is the trust-and-action close for Olena's scenario. It should feel calm and concrete: proof first, practical answers second, action last. The section must not invent social proof or make unsupported result promises.

```text
+--------------------------------------------------+
| Section Header                                   |
| path label | heading | support copy | trust note |
+--------------------------------------------------+
| Proof Summary                                    |
| heading                                          |
| parent proof | student result | progress proof   |
| internal proof gap note                          |
+--------------------------------------------------+
| Testimonials                                     |
| heading | filter chips                           |
| testimonial cards / quote slots                  |
| proof source note                                |
+--------------------------------------------------+
| Practical FAQ                                    |
| heading | support copy                           |
| trial | schedule | level | payment | format | fit|
+--------------------------------------------------+
| Final CTA                                        |
| heading | support copy | recap list              |

+--------------------------------------------------+
```
