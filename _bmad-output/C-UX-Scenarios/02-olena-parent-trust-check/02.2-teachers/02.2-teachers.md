## Overview

**Page Purpose:** Olena sees real teacher portraits, credentials, child-teaching experience, and warm teaching style.

**User Situation:** Olena arrives from the Kids / Parents Path section after deciding Fluyo sounds parent-aware, but she still needs to see the real people who may teach her child.

**Success Criteria:** Olena can quickly understand that Fluyo teachers are real, qualified, warm with children, and supported by a thoughtful matching process before she continues to lesson-experience proof.

**Entry Points:**
- Kids / Parents Path CTA
- Navigation menu
- Hero or audience-path trust link
- Direct anchor link to `#teachers`

**Exit Points:**
- Continue to Lesson Experience
- Ask about a teacher fit through Telegram
- Continue scrolling toward Results / Testimonials / FAQ / Final CTA

## Page States

| State | When | Appearance | Actions |
|-------|------|------------|---------|
| Default / loaded | Approved teacher data and proof assets are ready. | Header, teacher cards, credentials, teaching-style cards, and CTAs are visible. | Continue to Lesson Experience, open teacher details if enabled, open Telegram. |
| Asset pending | Teacher portraits, bios, or certificates are not approved yet. | Internal blocker/note visible in review; production hides missing proof or shows only approved teacher content. | Resolve assets before launch or reduce the section to approved proof only. |
| Loading | Teacher portraits or certificate thumbnails are loading. | Text renders immediately; image areas reserve stable space and show neutral placeholders. | CTAs remain usable. |
| Partial content | Some teacher cards are approved but others are missing. | Approved cards render; missing cards are not shown publicly. | Continue browsing; internal review keeps content-gap note visible. |
| Empty | No teacher profiles are approved for public use. | Production should not show a fake gallery; replace with a short real-team proof note only if approved. | Resolve teacher content before launch. |
| Error | Teacher image or certificate asset fails. | Card remains readable; failed media uses a neutral fallback and alt-safe label. | CTAs and text content remain available. |
| Success | User opens Telegram, opens teacher details, or scrolls to Lesson Experience. | External chat opens, details expand, or page scrolls; no inline success confirmation required. | User can return and continue browsing. |

## Validation And Constraints

| Validation area | Rule |
|-----------------|------|
| Form fields | None on this section. |
| Teacher profiles | Do not publish invented names, stock portraits, fake credentials, or generic bios presented as real. |
| Teacher portraits | Must be approved, privacy-safe, and cropped so the face remains visible. |
| Credentials | Must match real approved teacher credentials or certificates. |
| Child age claim | If shown, keep `6+` consistent with the product brief. |
| Profile detail interaction | If enabled, must be keyboard accessible and return focus correctly. |
| Certificate zoom interaction | If enabled, must use accessible dialog behavior and descriptive labels. |
| Telegram URL | Must be valid `https://t.me/fluyo_manager`. |
